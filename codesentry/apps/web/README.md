# Web (фронтенд-дашборд)

Статический сайт (HTML/CSS/JS), который раздаёт FastAPI (`apps/api/main.py`)
через `StaticFiles`. Никакой сборки/бандлера не требуется — открывается
напрямую в браузере по адресу http://localhost:8000 после запуска бэкенда.

- `index.html` — главный дашборд: список PR + график тренда техдолга + чат с ИИ по коду.
- `pr_detail.html` — детальная страница по конкретному PR со списком находок.
- `js/api.js` — обёртки над fetch к `/api/*`.
- `js/dashboard.js`, `js/charts.js` — логика страниц.

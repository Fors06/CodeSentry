# Архитектура CodeSentry

## Обзор

CodeSentry — локальная система код-ревью на базе офлайн-LLM (Ollama).
Никакого Docker, никакой внешней БД — только Python-процессы и файлы на диске.

```
┌─────────────┐     webhook      ┌──────────────┐
│   GitHub    │ ───────────────> │   FastAPI    │
│ (или локальная эмуляция)       │  apps/api    │
└─────────────┘                  └──────┬───────┘
                                         │ BackgroundTasks
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                    ▼
          ┌──────────────────┐ ┌─────────────────┐ ┌──────────────────┐
          │ git_integration   │ │ static_analysis  │ │   ai_review      │
          │ (clone, diff)     │ │ (ruff/bandit)    │ │ (Ollama LLM)     │
          └──────────────────┘ └─────────────────┘ └──────────────────┘
                    │                    │                    │
                    └────────────────────┼────────────────────┘
                                         ▼
                              ┌─────────────────────┐
                              │    persistence       │
                              │ (JSON-файлы + lock)  │
                              └──────────┬───────────┘
                                         │
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                    ▼
             data/prs/*.json    data/findings/*.json   data/metrics/*.json

                              ┌─────────────────────┐
                              │   web (static)        │◄── браузер (localhost:8000)
                              └─────────────────────┘

                              ┌─────────────────────┐
                              │   rag + Ollama        │◄── /api/ask (вопросы по коду)
                              │ (эмбеддинги в .npy)   │
                              └─────────────────────┘
```

## Ключевые решения

- **Без Docker**: единообразие окружения достигается через pyenv (фиксированная
  версия Python) + Poetry (`poetry.lock`) + единые настройки VS Code.
- **Без БД**: все данные — JSON-файлы в `data/`, доступ строго через
  `apps/persistence/repository.py`, конкурентная запись защищена `filelock`.
- **Локальный ИИ**: Ollama, запущенная нативно на машине разработчика,
  модель `qwen2.5-coder` для ревью и `nomic-embed-text` для RAG-эмбеддингов.
- **RAG без векторной БД**: эмбеддинги хранятся как `.npy` + JSON-метаданные,
  поиск — косинусное сходство через numpy (см. `apps/rag/retriever.py`).
- **Общий контракт**: `core/schemas.py` — единственный источник истины
  для структур данных, которые видят все модули.
